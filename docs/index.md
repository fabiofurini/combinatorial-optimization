# Combinatorial Optimization

Lecture notes on combinatorial optimization: knapsack, bin packing, vertex coloring, TSP, parallel machine scheduling and lot sizing, solved in every way: formulations and their properties, dynamic programming, heuristic and approximation algorithms, specialized algorithms.

## Parts of the course

- Combinatorial optimization problems
- Formulations and their properties
- Dynamic programming
- Heuristic algorithms
- Approximation algorithms
- Specialized algorithms

Author: [Fabio Furini](https://fabiofurini.github.io/), DIAG, Sapienza University of Rome.

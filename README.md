# Combinatorial Optimization Problems

Lecture notes on combinatorial optimization problems: knapsack, packing, vertex coloring, maximum clique, routing (TSP), parallel machine scheduling and lot sizing problems, their integer linear programming formulations with their properties and bounds, and ad hoc branch-and-bound algorithms (knapsack and DSATUR). With worked exercises, a catalogue of the problems, slides, interactive apps and a self-assessment quiz.

**Website: [fabiofurini.github.io/combinatorial-optimization](https://fabiofurini.github.io/combinatorial-optimization/)**

Prerequisites: [Linear Programming](https://fabiofurini.github.io/linear-programming/), [Integer Linear Programming](https://fabiofurini.github.io/integer-linear-programming/) and [Algorithms](https://fabiofurini.github.io/algorithms/).

The algorithms for these problems continue in three modules of the series: [Dynamic Programming](https://fabiofurini.github.io/dynamic-programming/), [Heuristic Algorithms](https://fabiofurini.github.io/heuristic-algorithms/) and [Approximation Algorithms](https://fabiofurini.github.io/approximation-algorithms/).

Part of the series *Operations Research and Mathematics* by [Fabio Furini](https://fabiofurini.github.io/) (DIAG, Sapienza University of Rome). Contents CC BY 4.0, code MIT.
